Einfaches Perzeptron programmiert in Java

#Das Perceptron ist dazu in der Lage 2 verschiedene Klassen voneinander zu unterscheiden, wenn diese linear trennbar sind. Die Anpassung des linearen Klassifizierers werden im Terminal aufgezeichnet. Außerdem wird der Lauf in einer GUI visuaisiert.

#(Java 17 oder neuer muss auf dem ausführenden Rechner installiert sein)

Starten:

Terminal im Ordner src öffnen und folgende Befehle ausführen:

javac --release 17 *.java 

java Main
